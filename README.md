# noita

My [Noita](https://noitagame.com/) mods: a few forks of other people's mods, plus one of my own.

| Mod | Origin |
|-----|--------|
| [AdvancedSpellInventory](mods/AdvancedSpellInventory) | Fork of [TheHorscht/AdvancedSpellInventory](https://github.com/TheHorscht/AdvancedSpellInventory). See its [CHANGELOG.md](mods/AdvancedSpellInventory/CHANGELOG.md) |
| [InventoryBags](mods/InventoryBags) | Fork of [TheHorscht/InventoryBags](https://github.com/TheHorscht/InventoryBags). See its [CHANGELOG.md](mods/InventoryBags/CHANGELOG.md) |
| [Cartographer](mods/Cartographer) | Fork of [willyamjarcand/noita_cartographer](https://github.com/willyamjarcand/noita_cartographer). See its [CHANGELOG.md](mods/Cartographer/CHANGELOG.md) |
| [WandBlueprints](mods/WandBlueprints) | Mine. Saves, edits and applies spell layouts for wands. See its [README.md](mods/WandBlueprints/README.md) |

## Setup

Run `./link.sh` to symlink every mod in `mods/` into Noita's `mods/` folder. By default that folder is the Steam install at `~/.local/share/Steam/steamapps/common/Noita/mods`. Set `NOITA_MODS` to use a different one.

See [mods/README.md](mods/README.md) for adding, removing and releasing mods, and for the M-Nee dependency.
